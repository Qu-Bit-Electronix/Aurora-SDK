# Aurora Overlay Panels

This folder includes the available overlay panel files for Aurora.

## FDN

The FDN overlay panel is a bespoke overlay for the FDN Verb alternate firmware. You can find the firmware file here: https://www.qubitelectronix.com/alternate-firmware/p/fdn-verb

## SDK

The SDK overlay panel is a generic overlay for creating your own custom firmware! White pill boxes allow for custom labeling using a marker. Just use isopropyl alcohol to remove the labeling and start anew!

## Ordering

The overlay gerber files are in a .zip file within each folder. Use the .zip file to upload to your PCB fab of choice, and order either panel!
